Metodologia

Os cenários usam os dados reais do teu negócio. O optimista é o percentil 80 do histórico de saldo diário líquido. O realista é a mediana. O pessimista é o percentil 20. Despesas sazonais (dias de reposição 2×/sem.) são detectadas automaticamente nos dados. O modelo requer no mínimo 5 dias de dados para projecções fiáveis.
